# Reflection

## What surprised me
How much the result depended on the instruction files rather than on the individual prompts. They are really nice to have for structure and overview instead of making big prompts to start off. I hadn't used the MVVM structure or TypeScript before, and STYLE.md turned out to be the most useful file for me. It made the thought process behind the code visible: which layer something belongs in, why, and what each file is responsible for. Without it, I often find Claude Code's structure hard to read since I have a vision on how I want my code to be structured and the AI does it it's own way. Once STYLE.md had a fixed folder layout and concrete brevity rules, the code became shorter and more consistent. CONTEXT.md kept the code readable and required it to pass the tests I had set out, and SPEC.md scoped the project and explained the rules of the game. Where SPEC.md was vague (for example "current settings summary"), that is exactly where the output drifted. I also didn't expect the AI to be confidently wrong about platform details, like the iOS status bar crash and letters being read as "capital C", which only showed up when I tested on a real phone.

## What I would do differently
I would put more into the scope at the start, writing the requirements in SPEC.md more precisely from the requirements made by the handout, instead of expanding the spec late in the project. That said, adjusting it along the way also worked well, because I could react to what I saw in the app. Testing on my phone after every step was also important: most real bugs were found there rather than by the unit tests, so I would keep doing that. To be honest, I'm not sure which parts would have been better without AI. I used Claude Code for the code itself and spent my own effort on the instructions, the design decisions, and testing and fixing details until it matched what I wanted.

Finally, I used the AI to create a code map: a short overview of the code as a whole and a flowchart of each sequence, such as one full round from Start to saving a score. That helped me understand how everything fits together. I then went through the questions from the handout one by one to make sure I can find and explain the relevant code.
